SB Launcher 3.3.0 — Rooms & friends reliability

- Room hosts can filter servers by free slots, player count and reported ping
- Re-entering a room no longer opens Roblox automatically
- Shared server joining now requires an explicit button press
- Friends presence refreshes faster and keeps the last valid snapshot during transient failures
- Stale friend responses can no longer overwrite newer account or presence data
- Windows packaging keeps SHA-256 verification working in stripped PowerShell environments
