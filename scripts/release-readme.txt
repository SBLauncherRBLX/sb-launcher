SB Launcher 3.5.0 — Windows x64

Close any running SB Launcher, then run SB Launcher.exe from this folder.
Keep the runtime and Assets folders beside the executable.
This is the normal release using the regular SB Launcher profile and update system.

Material You: Visuals > Presets > Material You.
Glass: Visuals > Textured visual effects > Glass.
Choose Frosted or Liquid Glass. Frosted defaults to Material You controls;
use Control style to choose Liquid Glass buttons, switches and sliders.
Visuals and game Settings include search fields that open matching sections automatically.
