# Upload to GitHub Pages

Do **not** upload any `.exe` or `.zip`. Those are ~94 MB and GitHub web upload will fail.

Live site: https://sblauncherrblx.github.io/SB-launcher-for-Roblox/

## Upload only these (into the **repo root**, same folder as `index.html`)

- `index.html`, `styles.css`, `download.js`, `privacy.html`, `terms.html`, `logo.png`
- The complete `assets/` folder
- From `downloads/parts/`: `manifest.json` + every generated `setup.partXX.bin`

Flat root is fine (that’s how the live repo is set up). Do not put a 94 MB `.exe` in the repo.

If Download still fails: re-upload only the updated `download.js`, wait 1–2 minutes, hard-refresh (Ctrl+F5).
